# 🌿 HomeCare AI

**Natural home remedies • Ancient wisdom • Modern care**

An AI-powered wellness assistant that provides safe home care guidance 
for common minor symptoms using natural remedies and time-tested wisdom.

## ✨ Features

- 🌱 Natural home remedy suggestions
- 🍯 Traditional healing tips
- ⚠️ Emergency symptom detection
- 💚 Safe & honest guidance
- 🌍 English + Telugu support

## 🚀 Tech Stack

- **Frontend:** Next.js + TypeScript + Tailwind CSS
- **Backend:** FastAPI + Python
- **AI:** OpenAI API
- **Database:** Supabase

## 🛠️ Setup

### Frontend
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`

### Backend
\`\`\`bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
\`\`\`

## ⚠️ Disclaimer

HomeCare AI provides general home-care information for minor symptoms only.
Not a substitute for professional medical advice.
Always consult a doctor for serious symptoms.
